# Bootcamp Kodie Academy — Projetos Front-End

Repositório de projetos desenvolvidos durante o bootcamp, organizados em pastas independentes.

## Projetos

### PULSO — Landing Page de Moda Esportiva

Landing page responsiva construída com HTML5 e CSS3, sem JavaScript.

- Código: [projetos/pulso-landing-page](projetos/pulso-landing-page)
- Demonstração: https://pablosena28.github.io/Bootcamp-Kodie-Academy/projetos/pulso-landing-page/

### Ruas do Rio — História dos Logradouros Cariocas

Aplicação React + Vite que consulta logradouros do município do Rio de Janeiro em uma API pública e cruza os resultados com uma base local de 100 logradouros, organizada por regiões e categorias de origem.

- Código: [projetos/ruas-do-rio](projetos/ruas-do-rio)
- Demonstração: https://ruas-do-rio.vercel.app/
- Tecnologias: React, Vite, JavaScript, CSS, Fetch API e localStorage
- API: ViaCEP

### Apoio em Dia — Tecnologia para o Impacto Social

MVP de atendimento estudantil com formulário, banco persistente, workflow de triagem e painel de acompanhamento.

- Código e execução: [projetos/apoio-em-dia](projetos/apoio-em-dia)
- Aplicação: https://apoio-em-dia-pablo.royalkiwi66.chatgpt.site (acesso público, sem login)
- Tecnologias: React, TypeScript, CSS, Vinext/Vite e SQLite/D1
- Desafio 3: problema, público, solução, funcionalidades e resultado esperado documentados no projeto.

## Organização

Cada trabalho do bootcamp fica em uma pasta própria dentro de `projetos/`.

```text
Bootcamp-Kodie-Academy/
├── projetos/
│   ├── pulso-landing-page/
│   ├── ruas-do-rio/
│   └── apoio-em-dia/
├── index.html
├── styles.css
└── README.md
```

O `index.html` da raiz funciona apenas como página de navegação entre os projetos.
