# PULSO — Landing Page de Moda Esportiva

Landing page responsiva de uma loja hipotética de roupas esportivas. O projeto foi desenvolvido para um desafio do bootcamp utilizando apenas HTML5, CSS3, Git e GitHub Pages.

## Tecnologias

- HTML5 semântico
- CSS3
- Flexbox e CSS Grid
- Git e GitHub Pages

O projeto não utiliza JavaScript, CSS inline ou a tag `<style>`.

## Funcionalidades e critérios

- estrutura semântica;
- hero com CTA;
- seção institucional;
- cards de produtos;
- galeria;
- contato;
- acessibilidade básica;
- layout responsivo para celular, tablet e desktop.

## Executar

Abra o arquivo `index.html` no navegador.
